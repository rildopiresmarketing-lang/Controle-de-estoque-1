# Controle de Estoque Android
App Android nativo para estoque de Natura, Boticário, Avon, Quem Disse, Berenice e Outra.
Recursos: cadastro, pesquisa, edição, entrada, saída, alerta de estoque baixo e resumo.
Os dados ficam salvos localmente no aparelho.
Abra no Android Studio e use Build > Build APK(s).
